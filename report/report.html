Problem Statement

Consider a set S of n line segments {s1,s2,s3....,sn}. Each line segment si (1 ≤ i ≤ n) is associated with a pair of points, its lower end-point and its upper end-point. We have to find and report the intersection points of these line segments.

Assumption: No overlapping Line segments

Overview of the Algorithm

The algorithm uses a sweep line (we have used a horizontal sweep line), which sweeps over the 2D plane passing through all possible event points. An event point is either the lower endpoint of a line or an upper endpoint of a line or the intersection point. The algortihm uses the fact that 2 adjacent/neighbouring line segments must among intersect first before intersecting other line segments. In this algorithm we repeatedly check immediate neighbouring line segments for interctions. Neighbours are decided based on the x coordinates of the point of intersections of the line segment with the sweep line. This ordering of the line segments is stored in another balance binary search tree called the status queue. We have used 3 functions to implement the algorithm.

  • FindIntersections(S): The segment endpoints are inserted into an event Queue (which is a balanced binary tree) ordered by decreasing order of their y-coordinates. If the y-coordinates are same they are ordered in increasing order of x coordinates. The max-point(largest y coordinate/ smallest x coordinate while comparing 2 points with same y coordinate) is removed from the event Queue till it is empty and a call is made to the HandleEventPoint function passing p as the parameter
  • HandleEventPoint(p): This function updates the status queue and reports a point as an interction point(if it is, along with the corresponding line segments). Each point is associated with 3 sets : L(p) [stores segments of which p is a lower end point],U(p) [stores segments of which p is a upper end point] and C(p) [stores segments which are in T and contain p]. A point is an intersection point iff |L(p) U U(p) U C(p)|>1. If the point is an upper endpoint, the corresponding segment is inserted into the queue and the resulting 2 neighbouring pairs (left and right Neighbours of the inserted segment now become immediate Neighbours with the inserted segment) is checked for intersections. If the point is an lower endpoint, the corresponding segment is removed from the queue and the resulting neighbouring pair (left and right Neighbours of the removed segment now become immediate Neighbours with each other) is checked for intersections. If the point is an intersection point, the ordering of the segments in the queue is swapped. While checking for intersections between 2 segments the function FindNewEventPoints(s1,s2,p) is called
  • FindNewEventPoints(s1,s2,p): This function checks if the segments intersect with each other. If the segments do intersect and their intersection point is below or to the right of the sweep line the intersection point is inserted into the status queue.

Data Structures and Classes

  • Event Queue : A BBST storing the event points
  • Status Queue: A BBST storing the segments intersecting the status queue
  • Vector: std cpp vectors used for storing set of segments, L(p),U(p),C(p)
  • Pair: Used to store an ordered pair
  • Segment: A segment data structure consists of 2 pairs namely it's lower and upper end points
  • Point: An event point data structure consists of it's x coordinate, y coordinate and the 3 sets associated with it i.e L(p),U(p) and C(p)
