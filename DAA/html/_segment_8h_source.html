Line Segment Intersections
Consider a set S of n line segments {s1,s2,s3....,sn}. Each line segment si (1 ≤ i ≤ n) is associated with a pair of points, its lower end-point and its upper end-point. We have to find and report the intersection points of these line segments (assumption: No overlapping segments)
